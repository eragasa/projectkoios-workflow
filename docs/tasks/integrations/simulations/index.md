# Simulations integration tasks

This directory indexes bounded integration work between
`projectkoios-workflow` and `projectkoios-simulations`.

Until an accepted Workflow SDK release exists, work here is limited to pinned
owner fixtures, compatibility review, and explicit adapter design. A task must
not require Simulations to import provisional Workflow types or treat a draft
Workflow API as a compatibility promise.
