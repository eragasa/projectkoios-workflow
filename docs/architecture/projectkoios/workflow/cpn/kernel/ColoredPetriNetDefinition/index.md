# `ColoredPetriNetDefinition`

## Responsibility

`ColoredPetriNetDefinition` is the immutable flat executable CPN IR. It contains closed color sets, places, transitions, variables, arcs, guards, inscriptions, capacities, priority, and selection-policy identity.

It contains no fragment hierarchy, domain adapter, provider, executable, authority, runtime state, or Python expression string. Fragment provenance is retained separately as composition evidence.
