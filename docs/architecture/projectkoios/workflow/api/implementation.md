# `projectkoios.workflow.api` implementation

## Responsibility

Bind only private Unix sockets or loopback interfaces. Require bearer capabilities with narrow scopes, reject cookies, validate hosts/origins where applicable, and enforce strict media-type and byte limits.

Wire schemas are versioned projections of SDK/service records. Raw private paths, credentials, PDFs, scientific arrays, and sealed operational locators are excluded from general status and Web subscriptions.
